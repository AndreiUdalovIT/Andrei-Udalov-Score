# Udalov Score

Футбольная статистика и прогнозы матчей топ-5 лиг и Лиги чемпионов. В разработке.

**Сайт:** [andrei-udalov-score.vercel.app](https://andrei-udalov-score.vercel.app)

## Проверки

Node.js 24 и pnpm из поля `packageManager` в `package.json`.

```powershell
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm format:check
pnpm test
```

### Браузерные тесты

При первом запуске установите браузеры:

```powershell
pnpm exec playwright install
pnpm test:e2e
```

Playwright сам собирает приложение и запускает его на `http://127.0.0.1:3100`.
Порт должен быть свободен. Все проекты используют одну свежую production-сборку;
настройка `VERCEL_ENV=preview` открывает витрину `/dev/kit` для проверки времени.
Сервер работает в UTC, тесты задают часовой пояс браузера отдельно.
Не запускайте одновременно другую сборку или `next dev` в той же папке: они
используют общий каталог `.next`.

Проверяются Chromium, Firefox, WebKit и мобильный Chromium (360 px): навигация,
404, адаптивная оболочка, темы и локальное время. Базовый набор не требует БД
или токена football-data. Продуктовые сценарии будут добавляться по мере разработки.
Проверка поиска сейчас проверяет сообщение-заглушку; перекрытие toast и нижнего
меню будет исправлено и покрыто регрессионным тестом в `fix/ui-foundation`.
Для skip-link в Chromium/Firefox проверяется первый Tab и переход фокуса к контенту.
В WebKit проверяется активация уже сфокусированной ссылки: его нативные настройки
обхода ссылок клавиатурой зависят от ОС.

```powershell
pnpm test:e2e --project=chromium
pnpm test:e2e:ui
pnpm test:e2e:report
```

При ошибке сохраняются скриншот и trace. HTML-отчёт находится в
`playwright-report/`, результаты — в `test-results/`; оба каталога исключены из Git.
В CI браузеры устанавливаются вместе с системными зависимостями, затем запускаются
те же тесты. При сбое отчёт и результаты сохраняются как артефакт на 7 дней.
